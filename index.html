    Questions

    How do I import the .pro files into ProPresenter (7 and later)?

    Unzip the download if you got a .zip, then in ProPresenter choose File > Import and pick the .pro file, or drag the .pro file onto your Library. The song arrives with its sections and play order already set up.

    How do I use the .txt or "Copy text" output with ProPresenter's text import?

    Save the .txt (or use Copy text and save it as a .txt file), then choose File > Import in ProPresenter and pick it. ProPresenter's text import has a delimiter setting that decides where one slide ends; set it so a blank line starts a new slide, which is how this output is laid out. ProPresenter names the presentation after the file, so name the file after the song.

    Does it work with FreeShow?

    Yes. Copy the song's text (Copy text, or the .txt), then in FreeShow create a new show (Shows, then New show) and paste it into the lyrics / Quick lyrics text box before pressing New show. The [Section] headings become groups and a blank line starts a new slide. FreeShow can also import ProPresenter files from File > Import, but text is the route we recommend.

    Is my PDF uploaded anywhere?

    No. Everything runs in your browser; the PDF is read on your device and never sent to a server. The Recent list is stored only in this browser (localStorage), holds the lyrics and your edits but not the PDF, and you can remove any entry with its x button.

    Which PDFs work?

    PDFs with a real text layer, such as chord charts exported from a word processor or song-planning app. Scanned pages and photos have no text to read, so they will not work. If you can select text in the PDF, it should. Otherwise, select all, copy, and use Paste lyrics.
